## Overview

This project is a personal portfolio website designed to present my
engineering background, professional experience, technical skills and
personal software development projects.

Built entirely with native web technologies, it focuses on simplicity,
responsiveness and maintainability, without relying on external
frameworks or dependencies.

## Features

- Responsive layout for desktop, tablet and mobile devices.
- Light and dark themes with persistent preferences using `localStorage`.
- Interactive project carousel with automatic and manual navigation.
- Keyboard navigation and touch gestures for the project carousel.
- Sticky navigation with active section highlighting.
- Accessible mobile navigation.
- Scroll animations with reduced-motion support.
- Profile image fallback.
- No external frameworks or dependencies.

## Tech Stack

| Technology   | Purpose                               |
| ------------ | ------------------------------------- |
| HTML5        | Semantic page structure               |
| CSS3         | Styling, responsive layout and themes |
| JavaScript   | Interactions and dynamic behaviour    |
| GitHub Pages | Static website hosting                |

## Getting Started

### Clone the repository

```bash
git clone https://github.com/nathan-brunet/nathan-brunet.github.io.git
cd nathan-brunet.github.io
```

### Run locally

No installation, dependencies or build process are required.

You can either:

- Open `index.html` directly in your browser.
- Use the Live Server extension in Visual Studio Code.
